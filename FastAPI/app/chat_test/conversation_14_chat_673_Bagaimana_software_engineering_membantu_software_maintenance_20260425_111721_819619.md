### response

Melansir konteks yang tersedia, software engineering membantu software maintenance dengan menggunakan teknik seperti:

* Refactoring untuk memperbaiki kualitas kode
* Deteksi "code smells" dan saran perancangan yang lebih baik
* Penggunaan agen bug-fixing untuk menemukan dan memperbaiki kesalahan
* Penggunaan model bahasa besar untuk membantu tes otomatis

Selain itu, software engineering juga membantu mengurangi beban kerja manusia dengan menggunakan analisis data untuk mendukung pengambilan keputusan yang lebih baik.
