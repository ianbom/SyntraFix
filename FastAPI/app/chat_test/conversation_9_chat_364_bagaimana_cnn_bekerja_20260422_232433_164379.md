### response

CNN (Convolutional Neural Network) bekerja dengan menggunakan lapisan-lapisan hierarkis untuk mengolah data 2D seperti gambar. Proses ini melibatkan beberapa lapisan, yaitu:

1. Lapisan konvolusi (convolution layer): dalam lapisan ini, filter atau kernel digunakan untuk mendeteksi pola-pola visual seperti garis, tekstur, dan pola lainnya di input.
2. Lapisan pooling (pooling layer): setelah lapisan konvolusi, lapisan pooling menggabungkan informasi penting dan menurunkan dimensiensi dari feature map.
3. Lapisan fully connected (fully connected layer): pada akhirnya, output dari beberapa lapisan konvolusi dan pooling dikirim ke lapisan fully connected untuk membuat prediksi.

CNN dapat mengenali pola-pola visual kompleks dengan menggunakan filter yang disesuaikan secara khusus. Dalam konteks penelitian ini, CNN digunakan untuk memprediksi posisi bola berdasarkan input dari kamera ZED.
